# WholesaleHub

WholesaleHub is a modern wholesale e-commerce platform built with React, TypeScript, and Vite.

## Features

- Browse wholesale products
- Product categories
- Shopping cart
- Wishlist
- Product comparison
- Bank transfer checkout
- Upload payment proof
- Order tracking
- Seller dashboard
- Admin dashboard

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Axios
- Tailwind CSS (or CSS Modules)
